    講座：劇場裡的雷射設計與演出控制

    Walter Nied · TouchDesigner 官方頻道 · 點時間直接跳到那一段 在 YouTube 觀看 ↗
    講座重點 · 創作

    少即是多。背景影像容易搶走觀眾對表演者的注意力；把預算和時間集中在一個元素（這裡是一台架高的雷射），作品反而更清楚。

    講座重點 · 安全

    可排練就是安全。表演者知道雷射何時、在哪裡出現，才能避開。所以有人在場時，雷射動作要固定，不要即興。

    講座重點 · 工作流程

    時間軸交給 Ableton，雷射長什麼樣交給 TouchDesigner，各做擅長的事。現場 DJ 的速度會飄，時間軸也要能跟著調。

    01安全

    雷射會造成永久性眼睛傷害

    碰任何器材之前，全班先記住這幾條：

    1. 光束永遠不對著人：投射區域內不能有人，也不能有鏡面或會反光的東西。
    2. 急停開關放在操作者手邊，並指定一位安全負責人。
    3. 接線、拔線前，先關掉雷射機或按下急停。
    4. 每次開機先測：按下急停，雷射機要立刻熄光。
    5. 暗光開場：RGB Scale 先調到 0.1～0.2。POP 沒有 Color 屬性時，輸出是全白最大亮度。
    6. 光束不動時能量集中在一點：避免單點圖形與很長的角點停留。
    7. 有人在場時，雷射動作要固定、可預期、排練過，不要即興。表演者知道光何時在哪裡，才能避開。
    8. 軟體停止（例如讓 TouchDesigner 停止運算）只是輔助，一定要有實體急停開關。
    9. 不要用相機或手機近距離對著雷射光束拍攝，可能打壞感光元件。
    10. 了解所在地區的雷射法規；部分地區要求操作者具備雷射安全員（LSO）資格。
    02硬體 · 系統

    一台雷射怎麼動起來

    TouchDesigner 算出每個點的位置和顏色，DAC 把數字變成電壓，雷射機裡的兩面振鏡再依電壓轉動，推著光點跑。

    03硬體 · 器材

    器材清單

    一台雷射的最小系統，加上現場一定要有的安全周邊。

    電腦跑 TouchDesigner，先確認能穩定 60 fps
    USB 線電腦接 DAC。USB 不適合拉長，電腦放在 DAC 旁邊
    DAC（Helios）把數字變成電壓。包裝只附 USB 線
    ILDA 線（DB-25）DAC 接雷射機。要用 ILDA 專用線，長距離走這條
    雷射機要有 ILDA 輸入；看清楚掃描速度與功率
    急停開關接在雷射機的 Interlock 上，一按就熄光
    鑰匙雷射機的總開關，不用時拔走
    腳架、安全鋼索雷射機一動 mapping 就要重做；吊掛一定加鋼索
    LaserCubeDAC 做在機身裡，USB 或網路直連，不需要 ILDA 線

    ILDA 接頭和舊式印表機線外型一樣（DB-25），但印表機線不保證每一腳都有接通，請用 ILDA 專用線。

    兩種 DAC：Helios 與 EtherDream

    項目Helios（USB）EtherDream（網路）
    接電腦USB 線網路線，接路由器／交換器或直接接電腦
    供電USB 供電，不用變壓器舊款用圓孔 DC 變壓器；Ether Dream 4 用 USB-C 供電
    距離USB 線短，電腦要放在 DAC 旁網路線可以拉長，電腦離雷射遠也沒關係
    多台每台一條 USB同一個網路接多台，靠 IP 區分
    TD 設定Type = Helios，Device 自動列出，沒出現按 ScanType = EtherDream，填 IP，Port 7765
    Helios 接線

    電腦 → USB → Helios → ILDA 線 → 雷射機（切到 ILDA 模式）。電源燈亮就可以在 TD 裡找到。

    EtherDream 接線

    ① 接電源 ② 網路線接到和電腦同一個網路 ③ ILDA 線接雷射機。IP 不用自己查：TD 的 EtherDream DAT 會列出網路上找到的機器和 IP。直接接電腦時，IP 會是 169.254 開頭，屬正常。

    EtherDream 找不到時

    確認同一個網路；Windows 防火牆要允許 TouchDesigner（第一次跳出詢問時按允許）；再按一次搜尋。

    04硬體 · 多台雷射

    一台 DAC，一路訊號

    要分開控制兩台雷射（畫不同內容、各自 mapping），就需要兩台 DAC，TD 裡也要有兩條輸出。

    1. 全部接好再掃描：所有 Helios 插上後只按一次 Scan。演出中不要按，它會斷開使用中的連線。
    2. 每台一個 Laser Device CHOP：Type 選 Helios，Device 各選一台。
    3. 一台一台確認：先開 #1，確認是哪台出光、方向對不對，再開 #2。
    4. 亮度、mapping 分開調：每台雷射機功率不同，同樣的 RGB Scale 亮度不會一樣。
    台數多、距離遠

    4 台以內、離電腦近，用 USB 的 Helios 最省。更多或更遠時，改用網路 DAC（例如 EtherDream），Laser Device CHOP 一樣支援。

    線怎麼拉

    USB 短、ILDA 長：電腦和 DAC 放一起，再用 ILDA 線拉到雷射機。線長依雷射機規格，訊號線不要和電源線綁在一起。

    兩台畫一模一樣的內容時，一個 Laser CHOP 可以同時接兩個 Laser Device CHOP。

    05邏輯 · 路徑

    雷射是一條路徑，不是一張圖

    出光角點停留blanking（關光移動）

    振鏡一次只能指向一個位置。光點沿著路徑跑完一圈（一個 cycle）再重來，跑得夠快，人眼就看成一張圖。

    左邊的光點是慢動作（放慢 200 倍）；淡淡的整個圖形是人眼看到的樣子。對應 TD 學生版的 ch05_path。用相機拍雷射，常會拍到光點走過的軌跡，正好證明人眼看到的圖形是「重畫」出來的。

    圖形
    圖形越大，路徑越長，一圈越久。取樣率固定 30000。
    –每圈 sample
    –一圈時間
    –每秒重畫

    每秒重畫 = 取樣率 ÷ 每圈 sample。低於約 50 次，人眼就會看到閃爍。要看的是一圈花多少 sample，不是 POP 有幾個點。

    06邏輯 · 時間預算

    一圈花多少 sample，決定會不會閃

    一圈的時間花在三件事：出光路徑的長度、角點停留、筆畫之間的 blanking。下面兩個示意各看一件。

    筆畫越多，blanking 越多

    出光角點停留blanking

    圓加矩形用 Copy POP 複製。每多一份就多兩筆，每一筆之間都要關光移動（灰色虛線）。

    –每圈 sample
    –blanking 佔比
    –每秒重畫

    TD 實測（48 kHz）：1 份 122 Hz、4 份 40 Hz。對應 TD 學生版的 ch06_budget。

    角點與導引點

    指令路徑振鏡實際走的路角點停留

    振鏡有慣性，急轉彎不停一下就會被切圓。角點（LasCorner = 1）原地停留讓振鏡追上；導引點（= 0）直接滑過。

    圖形
    LasCorner
    –每圈 sample
    –停留 sample
    –每秒重畫

    轉角要用角點，曲線用導引點。沒設 LasCorner 時，所有點都當角點：圓會白白多花很多 sample。振鏡慣性為示意。

    備註 · LasCorner 是什麼

    Laser CHOP 指定讀取的點屬性，不是自訂名稱。1 = 角點（原地停留），0 = 導引點（只輸出一次、直接滑過）。可以逐點設定。沒設時全部當角點；2025.30000 以前的版本沒有導引點，所以舊的 SOP 流程不會碰到它。

    備註 · 怎麼設

    真正的尖角設 1：矩形四角、星形頂點、折線轉折。曲線設 0：圓、弧線、Lissajous。全部設 1 不會比較穩：曲線上每點都停，一圈變長、容易閃，還會出現一串亮點。想要圓角請把幾何做成弧線，不要靠導引點讓振鏡「切圓」，那個弧度會隨雷射機改變。

    省時間的方法，依效果排序

    • 減少筆畫數：能連成一筆就不要分兩筆。分段改用 Color 漸暗，不要斷開 primitive。
    • 曲線用導引點：只在真正的轉角設 LasCorner = 1。
    • 縮短總路徑：圖形越大，一圈越久。
    • 取樣率不是加速鍵：Step Size 以時間計算，取樣率提高時每圈 sample 等比變多，一圈的時間幾乎不變。
    07軟體 · POP 網路

    一顆一顆接起來：POP 雷射網路

    每一顆 POP 只問一件事：它改寫了哪個屬性，還是改變了筆畫數？點節點、拉參數，看右下的數字怎麼變。

    –Point
    –Primitive（筆）
    –每圈 sample
    –每秒重畫
    Copy POP

    對應 TD 學生版的 ch07_pop_network，節點名稱和接法相同。點上方節點切換參數，Bypass 等於在 TD 把這顆節點關掉。示意用的近似模型，sample 數與 TD 實測約差 15%。

    Point 與 Primitive

    • Point：振鏡要經過的位置，以及在那裡的顏色（P、Color、LasCorner）。
    • Primitive：一筆連續出光的線。多一個 primitive，就多一次 blanking。
    實測 · 沒有 Color 屬性

    輸出 RGB 全部是 1.0（全白、最大亮度）。開發時請在最上游先加一顆 Attribute POP 設定 Color，並把 RGB Scale 調低。

    實測 · Rectangle POP 預設是「面」

    Surface Type 預設 Quadrilaterals。Laser CHOP 會走過四個點，但不畫回到起點的最後一條邊。請改成 Line Strips。Circle POP（Connectivity = Line Strip、Closed 開啟）則會完整封閉。

    為什麼不用 instancing

    算圖時 instancing 比 Copy POP 快，但 Laser CHOP 讀的是真實的點和 primitive。要讓雷射畫出多份，就必須用 Copy POP 產生真的幾何。

    線條工具 POP
    POP作用雷射用途
    Line POP一串控制點組成 line strip，可選 linear、bezier、hermite 內插手繪路徑、從資料生成圖形
    Line Resample POP依份數、間距或曲率重新分佈點，形狀不變讓點分佈均勻，配合導引點使用。不會直接減少 sample
    Line Smooth POP平均相鄰點，平滑線條（點數不變）noise 之後讓路徑更好掃
    Line Break POP依 LineBreak 屬性把點切成多條 line strip虛線、分段。切越多，blanking 越多
    SOP to POP把 SOP 幾何轉成 POP沿用現成的 SOP 素材或舊專案

    09軟體 · 路徑動畫

    把圖形「畫」出來：Write-on 與 Comet

    出光的一段振鏡仍要掃過（只調暗時）筆頭

    只讓路徑上的「一段」出光，筆頭（Path）往前推，圖形就像被畫出來。Write-on：從起點畫到終點後停住。Comet：固定長度（Length）的一段沿路徑跑，尾端漸暗。

    圖形
    Mode
    看不見的部分
    拖曳時暫停自動播放，放開後從這裡接著跑。
    –每圈 sample
    –每秒重畫
    –出光比例

    看不見的部分要剪掉，不能只調暗。顏色是 0 的點，振鏡還是要掃過去，一圈的時間不會變短。真的剪掉後，畫得越短，每秒重畫越高。

    Resolution：動畫解析度

    筆頭只能停在點上。正方形只有 4 個點，筆頭會從一個角跳到下一個角，所以要先把線切成很多等距的小段。切得越細，筆頭移動越順，但點越多、越吃效能。它只影響動畫，不影響雷射線條本身。

    角點要重新判斷

    切成小段後多出很多點。只有「原本是角點、而且路徑真的在這裡轉彎」的點才保留 LasCorner = 1，不然每個小點都會停留，一圈變得很長。

    任何圖形都能用

    Pattern、文字、圖片或影片描出來的輪廓，都能接在後面變成路徑動畫。對應 TD 的 laser_path（放在 source_switch 和 laser_color 之間，Mode = Off 時原樣通過）。

    10軟體 · 接上 DAC

    從 TouchDesigner 送到 Helios / EtherDream

    Laser CHOP 後面接 Laser Device CHOP，Type 選 Helios。Output Sample Rate 依雷射機的掃描速度設定，不超過 Helios 的 65,500。

    TouchDesigner 設定步驟

    1. 雷射機先不要出光：鑰匙關閉或在急停狀態，確認投射方向沒有人。
    2. 接 USB：Helios 的電源燈亮起。Windows 8 以上會自動安裝驅動；更舊的系統用 Zadig 安裝 WinUSB 驅動。
    3. 接 ILDA 線：Helios 的 DB25 接到雷射機的 ILDA 輸入。雷射機要切到 ILDA 模式，不是自走或聲控模式。
    4. Laser CHOP：Source = POP，Output Sample Rate 設成雷射機規格的掃描速度（例如雷射機標示 30K，就設 30000），不超過 65500。
    5. Laser Device CHOP：接在 Laser CHOP 後面，Type 選 Helios，Device 選單會自動列出接上的 Helios。沒出現時按 Scan。
    6. 先調暗：Red / Green / Blue Scale 調到 0.1～0.2，再把 Active 打開。
    7. 確認路徑後才加亮度：圖形方向不對時，在送進 Laser Device CHOP 之前用 Math CHOP 把 x 或 y 乘上 −1（或在 POP 用 Transform POP 翻轉）。不要把 Laser Device CHOP 的 X/Y Scale 設成負數：實測 Helios 會卡在角落、只剩一個點。
    改用 EtherDream

    Laser Device CHOP 的 Type 選 EtherDream，Network Address 填 EtherDream DAT 列出的 IP，Port 維持 7765，其餘步驟和 Helios 相同。Type 選錯時節點會變紅。

    Scan 的注意事項

    Scan 時不能有使用中的 Helios 連線，否則會被關掉。實測：沒接裝置時切換 Active 或 Scan，TD 會短暫掉幀（60 → 23 fps），之後恢復，屬正常現象。

    舊節點

    Helios DAC CHOP 已標示為 deprecated，請統一使用 Laser Device CHOP。

    上機後的實務觀念

    顏色不是線性的

    雷射二極體的亮度和輸入值不成比例，紅、綠、藍三色反應也不同：輸入 0.1 可能幾乎不亮，白色在低亮度時容易偏色。專業做法是每台雷射機各做一條「色彩曲線」校正。先有這個觀念，看到淡出不平順或白色偏色時，就知道原因。

    總亮度與平滑

    演出時準備一個總亮度推桿（Dimmer），隨時可以整體調暗。用 MIDI 控制器時，數值只有 0～127 階，先接 Filter CHOP 平滑，雷射動作才不會一格一格跳。

    換場館

    每個場館的投影位置都不一樣。把整體的位移、縮放、旋轉集中在一組參數（或 mapping），換場地時只調這一組，不用動每個圖形。

    Queue Time：延遲與穩定的取捨

    排隊中的 sample斷光（緩衝用完）

    Laser Device CHOP 先把 sample 放進緩衝排隊，再交給 Helios。Queue Time 就是隊伍的長度：越長越不怕 TD 卡頓，但你的操作要等越久才出光。

    常見問題

    症狀先檢查
    Device 選單是空的USB 有沒有接好、電源燈有沒有亮；先關掉其他使用中的 Laser Device CHOP，再按 Scan；舊版 Windows 要裝 WinUSB 驅動
    TD 沒錯誤，但完全沒光雷射機是否在 ILDA 模式、鑰匙與 interlock、RGB Scale 是否為 0、Laser CHOP 的 Active、POP 是否有 Color
    圖形左右或上下顛倒在 Laser Device CHOP 之前用 Math CHOP 把 x 或 y 乘上 −1（背投或鏡面反射時常見）。不要用負的 X/Y Scale
    閃爍每秒重畫太低：減少筆畫、曲線改導引點、縮小圖形
    轉角變圓、角落過亮Corner Hold 太小或太大；取樣率超過雷射機的掃描速度
    線段頭尾有拖尾或缺口調 Color Delay 與 blanking 參數
    操作後畫面慢半拍Queue Time 太長
    USB 裝置無法辨識（燈亮但系統認不到）依官方說明重新燒錄 Helios 韌體
